1. CONTEXTO E OBJETIVO DO PROJETO
================================================================================

O projeto "pvSolar Gateway" é um gateway profissional de monitoramento de
inversores solares com integração MQTT, computação de borda e suporte a
múltiplos inversores. O objetivo é ser o mais profissional possível.

Modelo de Negócio: Open Core
- Core (GPLv3): Gratuito - drivers, MQTT, edge computing, dashboard
- Premium (Comercial): AWS IoT, Azure IoT Hub, alertas avançados, suporte

Preferência do Usuário: "A mais profissional possível" — sempre escolher a
opção mais profissional quando há dúvidas de implementação.

6. PROBLEMAS ENCONTRADOS E SOLUÇÕES
================================================================================

6.1 Imports relativos quebrados
   Problema: Arquivos usavam `from ..core.config` mas testes importavam
             via sys.path direto, causando ImportError
   Solução: Migrar TODOS os imports para absolutos (`from core.config`)

6.2 pymodbus.constants.Endian indisponível
   Problema: `from pymodbus.constants import Endian` falha em pymodbus>=3.15
   Solução: Remover import do growatt/driver.py (não era usado)

6.3 Teste int32 com valor inválido
   Problema: [0xFF, 0xFF] = 16711935 (positivo), não negativo
   Solução: Usar [0xFFFF, 0xFFFF] = -1 para teste de negativo

6.4 Teste edge store sem inicialização
   Problema: get_stats() chamado sem initialize() → NoneType error
   Solução: Tornar teste async e chamar initialize() antes

6.5 Teste driver inválido
   Problema: Pydantic valida antes do create_driver(), então
             InverterConfig(driver="invalid") lança ValidationError
   Solução: Usar pytest.raises(Exception) genérico

6.6 pyproject.toml build backend
   Problema: `setuptools.backends._legacy:_Backend` não existe
   Solução: Usar `setuptools.build_meta`

6.7 License classifier conflict
   Problema: setuptools novo proíbe license classifiers com PEP 639
   Solução: Remover classifier "License :: OSI Approved" do pyproject.toml

6.8 Entry point quebrado
   Problema: `pvsolar-config=pvsolar.core.config:main` — config.py não tem main()
   Solução: Remover entry point inválido

11. CÓDIGOS DE ESTADO DOS INVERSORES
================================================================================

SMA:
- 0 = off, 100 = standby, 300 = starting, 600 = running
- 800 = fault, 1300 = shutdown

Huawei SUN2000:
- 0x0000 = standby, 0x0100 = grid-connected
- 0x0200 = running, 0x0201 = running (MPPT)
- 0x0300 = fault, 0x0301 = shutdown
- 0xA000 = standby (startup)
- 0xA001 = communicating
