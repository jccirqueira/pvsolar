Introdução
Visão geral do pvSolar Digital Twin

O pvSolar Digital Twin é o módulo de simulação digital do ecossistema pvSolar. Modela matematicamente painéis solares, simula cenários e otimiza o desempenho.

Modelo Matemático I-V
Equação do diodo
I = Iph - I0 * (exp(V / (n * Ns * Vt)) - 1) Onde: Iph = corrente fotogerada I0 = corrente de saturação V = tensão n = fator de idealidade (1.3) Ns = número de células (60) Vt = tensão térmica (kT/q)

Modelos de Degradação

ModeloEquaçãoUso
LinearF(t) = 1 - (rate × t)Padrão PRODIST
ExponencialF(t) = exp(-rate × t)Degradação acelerada
LogarítmicoF(t) = 1 - rate × ln(t+1)Estabilização inicial
StepDegraus a cada 5 anosModelo simplificado
Penalidade 1º Ano
O modelo inclui penalidade de 2% no primeiro ano (Light-Induced Degradation).

Instalação
Guia passo a passo
Clonar o repositório
git clone https://github.com/pvsolar/pvsolar-twin.git cd pvsolar-twin
Criar ambiente virtual
python -m venv venv venv\Scripts\activate
Instalar dependências
pip install -r requirements.txt
Configurar
cp config/twin.example.yaml config/twin.yaml # Editar config/twin.yaml
Executar testes
python -m pytest tests/ -v
Iniciar API
uvicorn src.app:app --host 0.0.0.0 --port 8006
Configuração
Arquivo twin.yaml
panel: rated_power_w: 400.0 efficiency: 0.22 voc: 37.5 plant: num_panels: 200 tilt_angle: 25.0 latitude: -23.55 degradation: model: "linear" annual_rate: 0.005 financial: capex_usd: 500000.0 energy_price_usd_kwh: 0.08
Docker
Deploy containerizado
docker-compose up -d docker-compose logs -f pvsolar-twin docker-compose down
