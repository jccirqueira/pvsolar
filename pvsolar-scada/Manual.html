Introdução
Visão geral do pvSolar SCADA

O pvSolar SCADA é o componente de visualização e controle do ecossistema pvSolar. Ele fornece uma interface HMI/SCADA completa para monitoramento em tempo real de usinas fotovoltaicas, conectando-se ao pvSolar Gateway (coleta) e pvSolar Analytics (ML).

Dashboard Principal
Visão geral da usina com potência, eficiência, meteorologia e status dos inversores.
Monitoramento de Inversores
Grid de até 6 inversores com detalhes DC/AC, eficiência e temperatura.
Meteorologia
Irradiância, temperatura, vento, umidade e rosa dos ventos.
Sistema de Alarmes
Alarmes com níveis, acknowledge, filtros e histórico.
Trends Históricos
Gráficos multi-parâmetro com exportação CSV.
Performance Scoring
Score geral, benchmarking e recomendações de melhoria.

Telas SCADA
6 telas de monitoramento

1. Dashboard

Tela principal com visão geral da usina. Inclui:

  • Plant Overview: nome, status LED, uptime, última atualização
  • Power Production: gauge de potência (kW), energia diária (kWh), eficiência, capacity factor
  • Weather: irradiância (W/m²), termômetro, vento, umidade
  • Inverter Status: total ativos/total, potência total, alarmes
  • Production Chart: linha potência vs irradiância (24h)

2. Inverters

Monitoramento detalhado dos inversores com grid 3x2 (até 6 inversores):

  • Cada inversor: LED status, potência, energia, eficiência, temperatura
  • Parâmetros DC/AC: tensão, corrente, frequência, fator de potência
  • Chart de tendência do inversor selecionado
  • Tabela de status detalhado

3. Weather

Dados meteorológicos completos:

  • Solar Resource: irradiância global, difusa, direta, refletida, pico de sol
  • Ambient: termômetro, umidade gauge, vento gauge, rosa dos ventos
  • Module Temperature: chart temperatura módulo vs ambiente
  • Production vs Irradiance: chart dual axis

4. Alarms

Sistema completo de alarmes:

  • Contadores por nível: critical, warning, info, acknowledged
  • Filtros e busca por texto
  • Tabela com detalhes e botão de acknowledge
  • Histórico de alarmes por hora (24h)

5. Trends

Visualização de dados históricos:

  • Controles: time range, refresh rate, pause, export CSV
  • Multi-parameter: potência, irradiância, temperatura, eficiência
  • Seleção via checkboxes
  • Estatísticas: min, max, avg, total, std dev, CF

6. Performance

Scoring e benchmarking:

  • Score geral com grade (A+ a F) e gauge
  • Componentes: PR, CEF, Availability, Efficiency
  • Benchmark: vs fleet, vs peer, vs histórico, vs melhor
  • Recomendações de melhoria

Instalação
Guia passo a passo
Clonar o repositório
git clone https://github.com/pvsolar/pvsolar-scada.git cd pvsolar-scada
Criar ambiente virtual
python -m venv venv venv\Scripts\activate # Windows # source venv/bin/activate # Linux
Instalar dependências
pip install -r requirements.txt
Configurar
cp config/scada.example.yaml config/scada.yaml # Editar config/scada.yaml com seus parâmetros
Executar testes
python -m pytest tests/ -v
Iniciar o servidor
python -m src.app -c config/scada.yaml
Requisitos
Python 3.10+, MQTT Broker (Mosquitto), pvSolar Gateway (para dados reais)
Configuração
Arquivo scada.yaml
mqtt: broker: "localhost" port: 1883 topics: - "pvsolar/+/telemetry" - "pvsolar/+/status" - "pvsolar/+/alarms" qos: 1 pvbrowser: host: "0.0.0.0" port: 5000 max_clients: 10 update_interval: 1.0 title: "pvSolar SCADA" gateway: url: "http://localhost:8000" analytics: url: "http://localhost:8001" plant: name: "Minha Usina Solar" capacity_kw: 100.0 num_inverters: 6 timezone: "America/Sao_Paulo"

Comandos TCP
Protocolo de comunicação

O servidor TCP aceita mensagens JSON terminadas por \n. Formato:

{ "type": 3, "command": "navigate", "params": { "screen": "dashboard" } }

Comandos Disponíveis

ComandoParâmetrosDescrição
navigate{ screen: "..." }Navega para uma tela
ack_alarm{ alarm_id: "...", user: "..." }Acknowledge um alarme
set_power_limit{ inverter_id: N, limit_kw: N }Define limite de potência
restart_inverter{ inverter_id: N }Reinicia um inversor

Sistema de Alarmes
Níveis e gerenciamento
NívelCorDescrição
Critical●Parada total, falha de hardware
Warning●Desvio de performance, temperatura alta
Info●Informação operacional
OK●Alarme resolvido

O sistema mantém até 1000 alarmes ativos. Alarmes antigos são removidos automaticamente. O timeout de auto-acknowledge é de 300 segundos.

Troubleshooting
Problemas comuns e soluções
Cliente pvBrowser não conecta
Verificar se o servidor está rodando na porta 5000 e se não há bloqueio de firewall.
Sem dados de telemetria
Verificar se o MQTT broker está rodando e se o pvSolar Gateway está publicando nos tópicos corretos.
Alarmes não aparecem
Verificar se o tópico pvsolar/+/alarms está configurado e o QoS é pelo menos 1.
