pvSolar Web
Unified Dashboard for Solar Plant Management
=============================================

OVERVIEW
--------
Next.js 14 + TypeScript + Tailwind CSS frontend for the pvSolar ecosystem.
Unified dashboard integrating all 9 pvSolar services (Gateway, Analytics,
SCADA, Reports, Fleet, Alert, Grid, Digital Twin, Auth) into a single UI.

TECH STACK
----------
- Next.js 14 (App Router)
- TypeScript 5.3
- Tailwind CSS 3.4
- Recharts (charts)
- React 18

PAGES
-----
- /auth           - Login page with JWT authentication
- /dashboard      - Real-time overview (power, energy, inverters, weather)
- /inverters      - Inverter details (status, voltage, current, temperature)
- /weather        - Meteorological data (irradiance, temp, humidity, wind)
- /alarms         - Alarm management (severity filters, acknowledge)
- /trends         - Time-series charts (power, irradiance, temperature)
- /performance    - PR, availability, efficiency, CEF, losses
- /fleet          - Multi-site management (sites, capacity, alerts)
- /alerts         - Centralized alert management
- /grid           - PRODIST compliance (voltage, THD, frequency, flicker)
- /twin           - Digital twin simulation (scenarios, what-if)

COMPONENTS
----------
src/
  components/
    layout/
      Sidebar.tsx          - Navigation sidebar with icons
      Header.tsx           - Top bar with user info and service status
    ui/
      StatusCard.tsx       - Metric card with icon and trend
      Card.tsx             - Generic content card
      Badge.tsx            - Status badge (success/warning/danger/info)
      LoadingSpinner.tsx   - Loading indicator
      EmptyState.tsx       - Empty state placeholder
    charts/
      PowerChart.tsx       - Line chart for power trends
      EnergyChart.tsx      - Bar chart for energy comparison
      DonutChart.tsx       - Pie/donut chart for distribution

LIB
---
src/
  lib/
    config.ts              - Service URLs and settings
    api.ts                 - API client for all services
    data.ts                - Data fetching with mock fallbacks

INSTALLATION
------------
npm install
npm run dev          # Development
npm run build        # Production build
npm run start        # Production server
npm run test         # Run tests
npm run lint         # Lint code
npm run typecheck    # TypeScript check

DOCKER
------
# Recomendado: compose da raiz do ecossistema (build multi-stage, standalone)
docker compose up -d web

# Entrypoint do container: node server.js (Next standalone), porta 3001
# URLs NEXT_PUBLIC_* viram caminhos relativos (/auth, /gateway, ...) no build
# Variante legado: cd docker && docker-compose up -d
