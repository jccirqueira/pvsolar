Introducao
Visao geral do pvSolar Web

O pvSolar Web e o frontend unificado do ecossistema pvSolar. Construido com Next.js 14, TypeScript e Tailwind CSS, ele integra todos os 9 servicos em uma unica interface moderna e responsiva.

Dashboard
Visao geral em tempo real com metricas principais.
Inversores
Monitoramento detalhado de cada inversor.
Clima
Dados meteorologicos e tendencias.
Alarmes
Gestao de alarmes com filtros por severidade.
Analytics
Performance ratio, eficiencia e perdas.
Frota
Gestao multi-site com rankings.

Funcionalidades
Componentes do sistema

UI Components

  • StatusCard: Card de metrica com icone e trend
  • Card: Card generico com titulo e acoes
  • Badge: Badge de status (success/warning/danger)
  • LoadingSpinner: Indicador de carregamento
  • EmptyState: Placeholder para lista vazia

Chart Components

  • PowerChart: Grafico de linha para tendencias de potencia
  • EnergyChart: Grafico de barras para comparacao de energia
  • DonutChart: Grafico de pizza para distribuicao

Auth Context

  • JWT login/logout com localStorage
  • Protecao de rotas
  • User context global
Instalacao
Guia passo a passo
Clonar o repositorio
git clone https://github.com/pvsolar/pvsolar-web.git cd pvsolar-web
Instalar dependencias
npm install
Configurar
cp config/web.example.yaml config/web.yaml # Editar URLs dos servicos
Executar testes
npm run test
Iniciar desenvolvimento
npm run dev
Build de producao
npm run build npm run start
