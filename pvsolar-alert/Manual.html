Introdução
Visão geral do pvSolar Alert

O pvSolar Alert é o sistema de notificações do ecossistema pvSolar. Ele permite envio de alertas por múltiplos canais com escalation automático e regras personalizáveis.

5 Canais
Email, SMS, Telegram, WhatsApp e Webhooks.
Escalation
4 níveis automáticos com contatos configuráveis.
Regras
Condições personalizáveis com 6 operadores.
Rate Limit
Controle inteligente por hora e dia.
Histórico
Log completo de todas as notificações.
API REST
API completa para integração.

Escalation Automático
4 níveis configuráveis

O sistema de escalation garante que alertas não sejam esquecidos. Se um alerta não é acknowledgado dentro do tempo configurado, ele é escalated para o próximo nível.

NívelTempoContatosCanais
Nível 15 minOperadorEmail
Nível 210 minEngenheiroEmail + SMS
Nível 315 minGerenteEmail + SMS + Telegram
Nível 420 minDiretorEmail + SMS + Telegram
Mapeamento Severidade → Nível
CRITICAL inicia no Nível 4, HIGH no Nível 3, MEDIUM no Nível 2, LOW/INFO no Nível 1.
Rules Engine
Regras personalizáveis

O Rules Engine avalia condições em tempo real e dispara alertas automaticamente.

Operadores Disponíveis

OperadorDescriçãoExemplo

rules: - id: "rule_overheat" name: "Superaquecimento" enabled: true conditions: - field: "temperature" operator: "gt" value: 80.0 severity: "high" channels: - email - sms escalation_level: "level_2"
Instalação
Guia passo a passo
Clonar o repositório
git clone https://github.com/pvsolar/pvsolar-alert.git cd pvsolar-alert
Criar ambiente virtual
python -m venv venv venv\Scripts\activate
Instalar dependências
pip install -r requirements.txt
Configurar
cp config/alert.example.yaml config/alert.yaml # Editar config/alert.yaml
Executar testes
python -m pytest tests/ -v
Iniciar API
uvicorn src.app:app --host 0.0.0.0 --port 8004
Configuração
Arquivo alert.yaml
email: enabled: true from_address: "alerts@pvsolar.com.br" telegram: enabled: true bot_token: "123456:ABC-DEF..." escalation: - level: "level_1" wait_seconds: 300 contacts: - name: "Operador" email: "op@pvsolar.com.br" rules: - id: "rule_overheat" name: "Superaquecimento" conditions: - field: "temperature" operator: "gt" value: 80.0 severity: "high"
Docker
Deploy containerizado
docker-compose up -d docker-compose logs -f pvsolar-alert docker-compose down
