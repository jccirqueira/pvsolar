Introdução
Visão geral do pvSolar Grid

O pvSolar Grid é o módulo de conformidade com o grid code brasileiro do ecossistema pvSolar. Verifica conformidade com PRODIST, ANEEL, INMETRO e ONS.

Compliance
Verificação automática PRODIST/ANEEL.
Qualidade
THD, FP, frequência, flicker, desquilíbrio.
FRT
LVRT/HVRT com curvas configuráveis.
Relatórios
Relatórios de compliance automáticos.
Histórico
Registro completo de eventos e medições.

Instalação
Guia passo a passo
Clonar o repositório
git clone https://github.com/pvsolar/pvsolar-grid.git cd pvsolar-grid
Criar ambiente virtual
python -m venv venv venv\Scripts\activate
Instalar dependências
pip install -r requirements.txt
Configurar
cp config/grid.example.yaml config/grid.yaml # Editar config/grid.yaml
Executar testes
python -m pytest tests/ -v
Iniciar API
uvicorn src.app:app --host 0.0.0.0 --port 8005
Configuração
Arquivo grid.yaml
connection: nominal_voltage_kv: 13.8 nominal_frequency: 60.0 prodist: voltage_min_pu: 0.9 voltage_max_pu: 1.1 thd_v_max: 8.0 power_factor_min: 0.925 rtu: enabled: true lvrt_curve: - time_ms: 0.0 voltage_pu: 0.0 - time_ms: 600.0 voltage_pu: 0.9
Docker
Deploy containerizado
docker-compose up -d docker-compose logs -f pvsolar-grid docker-compose down
Integração
Ecossistema pvSolar
pvSolar Gateway → pvSolar Grid → Compliance Report (dados) (verificação) (PRODIST/ANEEL)
