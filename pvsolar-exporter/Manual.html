Introducao
Visao geral do pvSolar Exporter

O pvSolar Exporter e o exportador de metricas do ecossistema pvSolar. Ele coleta dados de todos os servicos e os expoe no formato Prometheus para dashboards Grafana.

Prometheus Format
Metricas no formato padrao Prometheus (Gauge, Counter, Histogram, Summary).
11 Coletores
Coletores para todos os servicos pvSolar (Gateway, Analytics, SCADA, etc).
Custom Labels
Labels globais e por servico para filtragem avancada.
Auto-Scrape
Scraping automatico com intervalos configuraveis por servico.
API REST
Endpoints para health check, metrics, scrape manual e configuracao.
Timeout Config
Timeouts configuraveis por coletor para evitar bloqueios.

Instalacao
Guia passo a passo
Clonar o repositorio
git clone https://github.com/pvsolar/pvsolar-exporter.git cd pvsolar-exporter
Criar ambiente virtual
python -m venv venv venv\Scripts\activate
Instalar dependencias
pip install -r requirements.txt
Configurar
cp config/exporter.example.yaml config/exporter.yaml # Editar config/exporter.yaml com URLs dos servicos # Precedencia: PVSOLAR_CONFIG=/caminho.yaml > config/exporter.yaml > defaults
Executar testes
python -m pytest tests/ -v
Iniciar API
uvicorn src.api.app:app --host 0.0.0.0 --port 8010
Configuracao
Arquivo exporter.yaml
namespace: "pvsolar" scrape_interval_seconds: 15 scrape_timeout_seconds: 10 global_labels: environment: "production" region: "brasil" collectors: gateway: enabled: true url: "http://localhost:8000" interval_seconds: 15 labels: component: "data-collection" analytics: enabled: true url: "http://localhost:8001" interval_seconds: 30 labels: component: "ml-analytics"

Integracao Grafana
Como configurar
Configurar Prometheus
scrape_configs: - job_name: 'pvsolar' scrape_interval: 15s static_configs: - targets: ['pvsolar-exporter:8010'] metrics_path: '/metrics'
Adicionar Data Source no Grafana

Settings > Data Sources > Add > Prometheus

URL: http://prometheus:9090

Criar Dashboard

Use o namespace pvsolar_ para todas as queries:

# Energia total sum(pvsolar_gateway_messages_received) # Inversores online pvsolar_gateway_inverter_count # Uptime do sistema pvsolar_gateway_uptime_seconds
Docker
Deploy containerizado
# Recomendado: compose da raiz do ecossistema (docker-compose.yml) docker compose up -d exporter # Variante de config com URLs internas: docker/config/exporter.yaml # Legado: compose do proprio projeto docker-compose up -d docker-compose logs -f pvsolar-exporter docker-compose down
