Introdução
Visão geral do pvSolar Fleet

O pvSolar Fleet é a plataforma de gestão multi-site do ecossistema pvSolar. Ele permite gerenciar múltiplas usinas solares a partir de um único painel, consolidando dados, comparando performance e centralizando alertas.

Multi-Site
Gerencie dezenas ou centenas de usinas solares em um único lugar.
Comparação
Compare performance entre usinas com rankings e métricas.
Alertas
Alertas centralizados com escalation automático.
Regiões
Agrupamento por região com consolidação automática.
Rankings
Melhores e piores performers por métrica.
API REST
API completa para integração com outros sistemas.

Funcionalidades
Módulos do sistema

Site Manager

CRUD completo para gerenciar usinas:

  • Adicionar/remover usinas
  • Atualizar configurações
  • Agrupar por região
  • Trackear status (online/offline/manutenção)

Fleet Aggregator

Consolida dados de todas as usinas:

  • Métricas consolidadas da frota
  • Agregação por região
  • Total de capacidade e produção

Alert Aggregator

Centraliza alertas de todas as usinas:

  • Criação e gerenciamento de alertas
  • Escalation automático
  • Filtros por severidade e site
  • Estatísticas consolidadas

Comparison Engine

Compara e ranqueia usinas:

  • 6 métricas: Energy, PR, Efficiency, Availability, CEF, Score
  • Rankings (best/worst performers)
  • vs Fleet Average, vs Best Performer
  • Peer groups
Instalação
Guia passo a passo
Clonar o repositório
git clone https://github.com/pvsolar/pvsolar-fleet.git cd pvsolar-fleet
Criar ambiente virtual
python -m venv venv venv\Scripts\activate
Instalar dependências
pip install -r requirements.txt
Configurar
cp config/fleet.example.yaml config/fleet.yaml # Editar config/fleet.yaml com suas usinas # Precedencia: PVSOLAR_CONFIG=/caminho.yaml > config/fleet.yaml > defaults
Executar testes
python -m pytest tests/ -v
Iniciar API
uvicorn src.api.app:app --host 0.0.0.0 --port 8003
Configuração
Arquivo fleet.yaml
sites: - id: "site_1" name: "Usina Solar SP" gateway_url: "http://192.168.1.100:8000" analytics_url: "http://192.168.1.100:8001" capacity_kw: 500.0 num_inverters: 10 region: "sudeste" - id: "site_2" name: "Usina Solar RJ" gateway_url: "http://192.168.1.101:8000" analytics_url: "http://192.168.1.101:8001" capacity_kw: 300.0 num_inverters: 6 region: "sudeste" alerts: enabled: true max_alerts_per_site: 100 comparison: enabled: true default_metric: "pr"

MétricaDescriçãoMelhor

API HTTP
FastAPI — uvicorn src.api.app:app :8003
MétodoRotaDescrição
GET/healthSaúde do serviço (healthcheck do Docker)
GET/api/statusStatus e número de sites
GET/api/sitesLista todas as usinas
GET/api/sites/{id}Detalhe de uma usina (404 se ausente)
POST/api/sitesCria usina — 201 (422 em payload inválido)
DELETE/api/sites/{id}Remove usina (404 se ausente)
GET/api/fleet/summaryResumo consolidado da frota
GET/api/fleet/metricsMétricas de frota (404 sem dados)
POST/api/fleet/refreshForça nova coleta (502 se gateway off)
GET/api/fleet/alertsAlertas — filtros ?site_id= e ?severity=
GET/api/fleet/alerts/statisticsEstatísticas de alertas
GET/api/fleet/bestTop performers — ?metric=&count=
GET/api/fleet/worstPiores performers — ?metric=&count=
# Criar uma usina curl -X POST http://localhost:8003/api/sites -H "Content-Type: application/json" \ -d '{"id":"usina-01","name":"Usina Alpha","gateway_url":"http://localhost:8000", "analytics_url":"http://localhost:8001","capacity_kw":100,"num_inverters":4, "latitude":-23.55,"longitude":-46.63,"region":"sudeste"}'
Docker
Deploy containerizado
# Recomendado: compose da raiz do ecossistema (docker-compose.yml) docker compose up -d fleet # Variante de config com URLs internas: docker/config/fleet.yaml # Legado: compose do próprio projeto docker-compose up -d docker-compose logs -f pvsolar-fleet docker-compose down
Integração

pvSolar Gateway (cada usina) → pvSolar Fleet → Dashboard/Alertas pvSolar Analytics (ML) ↗ ↘ Rankings pvSolar SCADA (HMI) ↗ ↘ API REST
